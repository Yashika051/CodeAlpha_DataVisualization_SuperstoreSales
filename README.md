# 📊 Superstore Sales Dashboard

An interactive Business Intelligence dashboard built with **Streamlit**, **Pandas**, **Plotly**, **Matplotlib**, and **Seaborn** to analyze Superstore sales performance. The dashboard provides interactive filters, KPI cards, and visualizations to uncover trends, profitability, regional performance, customer segments, and product insights.

---

## 📌 Project Overview

This project transforms raw Superstore sales data into an interactive dashboard that enables users to explore business performance through dynamic visualizations. It helps identify sales trends, profitable product categories, regional performance, customer segments, and the impact of discounts on profitability.

---

## 🎯 Objectives

* Analyze sales and profit performance.
* Visualize key business metrics using interactive dashboards.
* Compare sales across categories, regions, and customer segments.
* Identify top-performing products.
* Understand how discounts influence profit.
* Present insights that support business decision-making.

---

## ✨ Features

* 📈 Interactive KPI Cards
* 🔍 Sidebar Filters (Region, Category, Customer Segment)
* 📊 Monthly Sales Trend
* 📦 Sales by Category
* 🌍 Sales by Region
* 👥 Sales by Customer Segment
* 🏆 Top 10 Products by Sales
* 💸 Discount vs Profit Analysis
* 📊 Profit by Sub-Category
* 📌 Automated Business Insights

## 🚀 How to Run

1. Clone the repository.

```bash
git clone https://github.com/Yashika051/CodeAlpha_DataVisualization_SuperstoreSales.git
```

2. Navigate to the project folder.

```bash
cd CodeAlpha_DataVisualization_SuperstoreSales
```

3. Install the required libraries.

```bash
pip install -r requirements.txt
```

4. Run the Streamlit application.

```bash
streamlit run app.py
```

## 📈 Key Insights

* Technology generated the highest overall sales.
* The West region achieved the highest sales performance.
* Consumer customers contributed the largest share of revenue.
* Large discounts were associated with lower profitability.
* A small number of products accounted for a significant portion of total sales.
